# Chrome Web Store 審査用情報

## 拡張機能の詳細な説明

RSS Decks は、RSS/Atom フィードを1つのダッシュボードにまとめる拡張機能です。各フィードの新着記事を最大15件までブロック形式で表示し、ブロックの移動、グループ分け、並べ替え、タイトルや色の編集ができます。記事は拡張機能内のサイドペインまたは新しいタブで開けます。フィード項目に音声エンクロージャーが含まれる場合は、音声を再生できます。内蔵デモには、再生機能確認用の3秒のサイン波テスト音を含みます。これは人の声や読み上げではありません。Webサイトへのショートカット、サムネイルとサイドペインの表示設定、日本語／英語の切り替え、設定のJSON形式でのインポート／エクスポートにも対応しています。フィード追加時に取得し、「更新」ボタンから再取得できます。

フィードが保存されていない場合は、Zenn、Qiita、Yahoo!ニュースのサンプルフィードを表示します。フィードや表示設定はChromeの同期ストレージに保存されます。

## 単一用途

この拡張機能の用途は、RSS/Atomの更新情報を1つのダッシュボードに集約し、整理して読むことです。フィードブロック、グループ、記事表示、音声再生、Webサイトへのショートカット、設定機能は、すべてフィードを読む操作を支援します。

## 権限ごとの必要な理由

- **`storage`** — フィードURL、表示設定、グループ、Webサイトへのショートカット、記事ペインの設定をChromeの同期ストレージに保存し、拡張機能を再度開いたときに利用できるようにします。Chromeの同期機能による同期にも使われます。
- **`alarms`** — バックグラウンドで4時間ごとの繰り返しアラームを登録します。現行バージョンでは、フィードの取得はフィード追加時またはユーザーが「更新」を選んだときに行われ、アラーム自体がフィードを取得することはありません。
- **`declarativeNetRequest`** — Webサイトがフレーム内表示を制限している場合に、記事を拡張機能のサイドペインで表示するために使います。`X-Frame-Options` と `Content-Security-Policy` のレスポンスヘッダーを除去するルールは、RSS Decksから読み込まれたサブフレームにのみ適用され、拡張機能外で開いたページは変更しません。
- **任意のホストアクセス（`http://*/*`、`https://*/*`）** — インストール時には許可されません。ユーザーが追加・インポートしたフィードの取得、フィード更新、サイドペインで記事を開く操作に必要なHTTP/HTTPSオリジンごとに、RSS Decksがアクセス許可を要求します。フィードのオリジンへのアクセスはRSS/Atom文書の取得に、記事のオリジンへのアクセスは選択したページのサイドペイン表示に必要です。許可はChromeの確認画面でユーザーが判断でき、拒否したオリジンへのアクセス権は付与されません。

## 審査用テスト手順

アカウント登録やログインは不要です。テスト用のアカウント情報はありません。

1. Chrome ウェブストアから RSS Decks をインストールし、ツールバーのアイコンを選択します。
2. 外部フィードに依存せず画面を確認するには、RSS Decks のロゴを10回クリックします。5回目に表示されるアラートを閉じてから、さらにクリックしてください。内蔵デモではサンプルのフィード、グループ、記事、画像を確認できます。保存済み設定は変更されず、Webサイトへのアクセス許可も要求されません。「DEMO」と表示されている間にロゴをもう一度クリックすると通常のダッシュボードに戻ります。
3. フィード取得とホストアクセスを確認するには、「追加」を選び、`https://zenn.dev/feed` を入力して追加します。Chromeのオリジン許可が表示されたら許可してください。フィードがブロックとして表示され、記事が読み込まれます。「更新」を選ぶと再取得できます。
4. フィードの記事を選ぶとサイドペインで開きます。記事が未許可のオリジンにある場合は、Chromeの許可画面でそのオリジンを許可してください。ペインの「新しいタブで開く」ボタンで別の表示方法も確認できます。
5. グループとWebサイトへのショートカットを追加し、フィードをグループに移動します。「設定」から設定をJSON形式でエクスポートし、再インポートできます。これらの操作にログインは不要です。
6. 音声再生を確認するには、DEMOモードの「Pocket Observatory」フィードを開き、最初の記事「[TEST TONE] A brighter dot on the evening horizon」の再生ボタンを選択してください。3秒のサイン波が再生されます。このテスト音には人の声、読み上げ、ポッドキャストの内容は含まれません。

外部Webサイトにアクセスできない環境でも、手順2の内蔵デモでダッシュボードと記事ペインを確認できます。
